## 27b interactive logo

`index.html` is an interactive logo. Move your mouse over it and the letters react, then settle back.

- Open `index.html` in a browser, or deploy the folder to Vercel as a static site. There's no build step.
- **logo** panel: type your own text (Shift + Enter for a second line), pick a font, and set the text and background colours.
- **effects** panel: choose one of 10 effects (Mouse Grid, Liquid, Pixel Trail, RGB Split, Slices, Smear, Wobble, Halftone, Invert, Magnify) and tweak its sliders.
- **Share effect** copies a link that saves everything: text, font, colours, effect and slider values. Anyone who opens it sees the same thing.
- Press `h` to hide or show the panel.
