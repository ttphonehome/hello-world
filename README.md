## 27b interactive logo

`index.html` is an interactive "27b" logo. Move your mouse over it and the letters break apart into blocks, then settle back.

- Open `index.html` in a browser, or deploy the folder to Vercel as a static site. There's no build step.
- Use the debug panel (top right) to switch effects (Mouse Grid, Liquid, Pixel Trail, RGB Split) and tweak the sliders.
- **Share effect** copies a link that saves your current settings.
- Press `h` to hide or show the panel.
